01AI INFRA

AI 基础设施AI INFRASTRUCTURE

如果 AI 是一家明星餐厅，Infra 就是整座城市的电网、水管、道路和中央厨房。食客看不见它们，可没有它们，一道菜也做不出来。

它是什么

一层一层往上搭：最底下是电力和机房；往上是 GPU 芯片，真正“算”的地方；再往上是把几万张芯片连在一起的高速网络、存数据的仓库、分派任务的调度系统；最顶层才是你用到的 AI 服务。训练模型拼的是“蛮力”，回答问题拼的是“速度”。

从哪来

  1. 2006NVIDIA 推出 G80 显卡，第一款支持 CUDA 的 GPU，显卡开始做“通用计算”
  2. 2012AlexNet 在卧室里用两块游戏显卡训练完成，赢下 ImageNet 比赛，深度学习从此起飞
  3. 2025OpenAI、软银等宣布 Stargate 计划，目标到 2029 年投入 5000 亿美元
  4. 2026Dell'Oro 预测全球数据中心年度资本开支将首次超过 1 万亿美元

你见过的它

NVIDIA GPUGoogle TPUAWS / Azure / Google Cloud向量数据库Kubernetes 调度

五层发光的“地基”自下而上堆叠，数据像光点一样沿着柱子向上输送。

02HARNESS

马具 · 外壳AGENT HARNESS / EVAL HARNESS

模型像一匹力大无穷却不认路的野马。Harness 本义是“马具”，就是缰绳、马鞍和车架。套上之后，马力才变成能拉货、会转弯、不翻车的马车。

它是什么

Agent = Model + Harness

模型本身只会“接着往下写字”：记不住事，也动不了手。Harness 是模型之外的一切：调用工具（读文件、上网、跑代码）、管理记忆和上下文、设置权限与护栏、检查结果。同样的模型，配上更好的 harness，就是更能干的智能体。

Eval Harness 是另一个意思：统一的“驾考场地”，给所有模型出同样的题、用同样的标准打分。

从哪来

  1. 2021EleutherAI 发布 lm-evaluation-harness，后来成为 Hugging Face 开源模型排行榜的后端
  2. 2023–24研究界把模型外面这一层叫作 scaffolding（脚手架）
  3. 2026 初LangChain 的工程文章推广了 “Agent = Model + Harness”
  4. 2026.02“harness engineering” 一词流行，Mitchell Hashimoto 最早提到

你见过的它

Claude CodeCodex CLICursorClaude Agent SDKlm-evaluation-harness

中心发光的核心是模型；金色多面体笼子和环绕的轨道就是 harness，轨道上的小球是工具、记忆、护栏……

03AGENT LOOP

循环THE AGENT LOOP

就像厨师试菜：尝一口、加点盐、再尝一口，直到味道对了才上桌。智能体干活也是一圈一圈“试”出来的。

它是什么

智能体不是一问一答，而是一个循环：思考下一步 → 行动（调用工具）→ 观察结果 → 验证对不对，不满意就再转一圈。它还必须带着“刹车”：最多转几圈、最多花多少钱、什么算完成。没有刹车，就可能原地打转。

从哪来

  1. 2022.10Shunyu Yao 等人发表 ReAct 论文，让模型“边推理边行动”，交替进行
  2. 2023AutoGPT 等开源项目让“AI 自己循环干活”出圈
  3. 2024.12Anthropic 发表《Building Effective Agents》，把智能体定义为“在循环里使用工具的模型”

你见过的它

编程助手：改代码 → 跑测试 → 再改Deep Research：搜 → 读 → 再搜ReAct Agent

粒子沿着光环一圈圈奔流；最亮的“彗星头”每经过一站，那一步就被点亮。

04GRAPH

图 · 网络COMPUTATION / KNOWLEDGE / AGENT GRAPH

Graph 就是一张地铁线路图：站点是“节点”，轨道是“连线”。在 AI 里，它有三种常见用法。

它是什么

计算图神经网络的每一步计算都是一个站点。沿着线路倒着走一遍，就能算出每个参数“该往哪儿改”，这是 AI 能自己学习的工程基础（自动微分）。
知识图谱把知识存成“谁—什么关系—谁”，比如 达·芬奇 —创作→ 蒙娜丽莎。
编排图LangGraph 把智能体的工作流画成图，允许有“环线”回到之前的步骤，也就是用图来画上一章的 Loop。

从哪来

  1. 2010Theano 引入计算图与自动微分；2015 年 TensorFlow 发布
  2. 2012.05Google 发布知识图谱，口号是 “things, not strings”
  3. 2024.01LangChain 发布 LangGraph，支持带环的智能体流程
  4. 2024Microsoft Research 推出 GraphRAG，让大模型先抽取知识图谱再检索

你见过的它

PyTorch / TensorFlowGoogle 知识图谱GraphRAGLangGraph

光点沿着连线在节点之间穿梭，就像信息在网络里传递。
